asset-inventory

One command to inventory your OpenCode setup — every plugin, skill, command, MCP server, agent, and host capability, each with provenance.

一条命令，盘清你的 OpenCode 环境——每个插件、Skill、命令、MCP、Agent 与外层应用能力，都带来源追溯。

Core idea: inventory what the machine can actually invoke, not which files exist on disk. Every row answers three questions — what it is, who brought it in, how to use it; the source must name the specific bringer, never a vague "some plugin".

主体思想：盘点的不是磁盘上有哪些文件，而是这台机器真正能调用什么。每行回答三个问题——是什么、谁带来的、怎么用；来源必须具体到带来者，绝不写"某个插件"。

Highlights

特点

  • Provenance: built into OpenCode, brought by a plugin, created by you, or injected by a host app
  • Four-state labels: ✅available / ❌disabled / 📦shelf-only / 🚫absent
  • Read-only and masked: changes no config; masks keys, paths, and private project names by default
  • Host-aware: binary-scans the app bundle for injected commands that plain grep misses
  • Diff mode: paste the previous JSON and get only additions and removals
  • 来源可追溯：OpenCode 自带、插件带来、你自建，还是外层应用注入
  • 四态标注：✅可用 / ❌已禁用 / 📦仅货架未装 / 🚫不存在
  • 只读脱敏：不改任何配置，默认打码密钥、路径与私有项目名
  • 外层应用感知：二进制扫描应用包，抓出普通 grep 漏掉的注入命令
  • 差异模式：贴上次 JSON，只输出增删
