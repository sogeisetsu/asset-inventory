asset-inventory.json

The same 7 tables, machine-readable — for diffing and migration.

与 7 张表等价、机器可读 —— 用于差异对比与迁移。

What it is

它是什么

A standalone JSON array with one element per Markdown data row. Its primary key is table + name. The table field is always the numeric 1–7 and never changes with the output language — that is what makes cross-run diffing possible even when the tables themselves are written in a different language.

一个独立的 JSON 数组，每个 Markdown 数据行对应一个元素。主键为 table + name。table 字段恒为数字 1–7，不随输出语言变化 —— 这正是能跨运行做差异对比的原因，即使表格本身换成了另一种语言。

Fields

字段

tablenumeric 1–7 — the table this row belongs to (never localized)数字 1–7 —— 该行所属的表（不本地化）
namethe asset name, as shown in the Markdown资产名，与 Markdown 中一致
sourcethe three-part provenance with confidence三段式来源，含可信度
state✅available / ❌disabled / 📦shelf-only / 🚫absent✅可用 / ❌已禁用 / 📦仅货架未装 / 🚫不存在
confidence✅verified / ✅docs / ⚠️inferred✅实测 / ✅文档 / ⚠️推断
invokethe invocation path(s)调用路径

Diff mode

差异模式

Ask "what changed since last time?" and paste the previous JSON — you get only the added and removed rows, keyed by table + name. The full tables are never re-dumped.

问"和上次比有什么变化？"并贴入上一次的 JSON —— 只会得到按 table + name 键控的新增与删除行，绝不重新倾倒完整表格。
