Qué es

inventory.md is the core output: one Markdown file containing 7 fixed tables that map everything your machine can actually invoke. Tables 1–5 and 7 have five columns (Name | Source | How to call | When to use | What it does); Table 6 (Agents) adds a sixth, Model chain.

inventory.md 是核心产物：一个 Markdown 文件，含 7 张固定表，把本机真正能调用的一切列出来。表 1–5、7 为五列（名称 | 来源 | 调用方式 | 何时用 | 干什么）；表 6（Agent）多一列 模型链。

Convenciones clave

  • State markers: ✅available / ❌disabled / 📦shelf-only / 🚫absent / 🛑broken — localized to the output language.
  • Confidence: ✅verified / ✅docs / ⚠️inferred appended to every source.
  • What it does is one detailed paragraph answering: how to invoke, when to use, and what happens after.
  • Read-only: the skill never edits your config; keys, tokens, and private paths are masked by default.
  • 状态标记：✅可用 / ❌已禁用 / 📦仅货架未装 / 🚫不存在 / 🛑已损坏 —— 随输出语言变化。
  • 可信度：每个来源后附 ✅实测 / ✅文档 / ⚠️推断。
  • 干什么是一段详细文字，回答：怎么调用、何时用、用了之后会发生什么。
  • 只读：skill 绝不改动你的配置；密钥、token、私有路径默认打码。
