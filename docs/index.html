为什么会有这个 skill
Why it exists

为什么需要它

Why you need it

OpenCode 环境膨胀得很快。几周下来，你装了十几个插件、好几套 Skill、一堆 MCP，还有外层应用自带的各种能力。然后某天你突然想不起来：那个命令是哪个插件带的？那个 Agent 为什么禁用了？换台机器的话，我得装什么？

OpenCode environments grow fast. After a few weeks you've installed a dozen plugins, several skill sets, a bunch of MCP servers, and there are all those host-injected capabilities. Then one day you realize: which plugin brought that command? Why is that agent disabled? If I switch machines, what do I need to install?

asset-inventory 就是来回答这些问题的。它不是靠你手动填表，而是直接从机器上实际可调用的能力出发——读配置、扫缓存、查注册表、跑命令验证——给你一份可信的完整答案。

asset-inventory exists to answer these questions. It doesn't ask you to fill in a form — it starts from what this machine can actually invoke: reads configs, scans caches, checks registries, runs commands to verify — and gives you a trustworthy, complete answer.

安装方式
Installation

两种装法，选适合你的

Two ways to install — pick what fits

全局装 = 所有项目都能用；项目级装 = 只跟着当前项目走。先克隆仓库（或下载 ZIP 解压）得到 asset-inventory/ 文件夹，cd 进它里面，只复制三样东西（SKILL.md、references/、examples/——README 等文档不用装）。

Global = available in all projects; project-level = stays with the current project only. First clone the repo (or download & unzip the ZIP) to get an asset-inventory/ folder, then cd into it and copy only three things (SKILL.md, references/, examples/ — the README and docs are not needed).

🌍 全局安装 🌍 Global Install 所有项目可用 All projects

装到 OpenCode 的全局 skills 目录，每个项目都能调用。

Install into OpenCode's global skills directory — available to every project.

macOS / Linux
mkdir -p ~/.config/opencode/skills/asset-inventory && cp -r SKILL.md references examples ~/.config/opencode/skills/asset-inventory/
Windows (PowerShell)
New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\.config\opencode\skills\asset-inventory"; Copy-Item -Recurse SKILL.md, references, examples -Destination "$env:USERPROFILE\.config\opencode\skills\asset-inventory\"

📁 项目级安装 📁 Project-Level Install 仅当前项目 Current project only

装到当前项目内，跟着项目走，适合团队共享或临时使用。把 <项目根目录> 换成你的项目路径。

Install inside the current project — travels with the repo, good for team sharing or temporary use. Replace <project-root> with your project path.

macOS / Linux
mkdir -p <项目根目录>/.opencode/skills/asset-inventory && cp -r SKILL.md references examples <项目根目录>/.opencode/skills/asset-inventory/
mkdir -p <project-root>/.opencode/skills/asset-inventory && cp -r SKILL.md references examples <project-root>/.opencode/skills/asset-inventory/
Windows (PowerShell)
New-Item -ItemType Directory -Force -Path "<项目根目录>\.opencode\skills\asset-inventory"; Copy-Item -Recurse SKILL.md, references, examples -Destination "<项目根目录>\.opencode\skills\asset-inventory\"
New-Item -ItemType Directory -Force -Path "<project-root>\.opencode\skills\asset-inventory"; Copy-Item -Recurse SKILL.md, references, examples -Destination "<project-root>\.opencode\skills\asset-inventory\"
