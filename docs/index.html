为什么会有这个 skill
Why it exists

装了什么？谁带的？什么时候该用？

What did I install? Who brought it? When should I use it?

OpenCode 环境膨胀得很快。几周下来，你装了十几个插件、好几套 Skill、一堆 MCP，还有宿主自带的各种能力。然后某天你突然想不起来：那个命令是哪个插件带的？那个 Agent 为什么禁用了？换台机器的话，我得装什么？

OpenCode environments grow fast. After a few weeks you've installed a dozen plugins, several skill sets, a bunch of MCP servers, and there are all those host-injected capabilities. Then one day you realize: which plugin brought that command? Why is that agent disabled? If I switch machines, what do I need to install?

asset-inventory 就是来回答这些问题的。它不是靠你手动填表，而是直接从机器上实际可调用的能力出发——读配置、扫缓存、查注册表、跑命令验证——给你一份可信的完整答案。

asset-inventory exists to answer these questions. It doesn't ask you to fill in a form — it starts from what this machine can actually invoke: reads configs, scans caches, checks registries, runs commands to verify — and gives you a trustworthy, complete answer.
