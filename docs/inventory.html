inventory.md

The 7-table inventory — the main deliverable.

7 张表的盘点清单 —— 主产物。

What it is

它是什么

inventory.md is the core output: one Markdown file containing 7 fixed tables that map everything your machine can actually invoke. Tables 1–5 and 7 have five columns (Name | Source | How to call | When to use | What it does); Table 6 (Agents) adds a sixth, Model chain.

inventory.md 是核心产物：一个 Markdown 文件，含 7 张固定表，把本机真正能调用的一切列出来。表 1–5、7 为五列（名称 | 来源 | 调用方式 | 何时用 | 干什么）；表 6（Agent）多一列 模型链。

The 7 tables

7 张表

1Plugins & companion software — real product names插件与配套软件 —— 用真实产品名
2Skills & commands each software/plugin brings各软件/插件带来的 Skill 与命令
3Built-in commands & built-in skills原生命令与原生 Skill
4Custom skills, commands & host-injected commands自定义 Skill、命令与外层应用注入命令
5MCP — every server, local & remoteMCP —— 每个 server，本地与远端
6Agents — with their model chainsAgent —— 含模型链
7Host capabilities — behavior rules, browser, etc.外层应用能力 —— 行为规则、浏览器等

Key conventions

关键约定

  • State markers: ✅available / ❌disabled / 📦shelf-only / 🚫absent — localized to the output language.
  • Confidence: ✅verified / ✅docs / ⚠️inferred appended to every source.
  • What it does is one detailed paragraph answering: how to invoke, when to use, and what happens after.
  • Read-only: the skill never edits your config; keys, tokens, and private paths are masked by default.
  • 状态标记：✅可用 / ❌已禁用 / 📦仅货架未装 / 🚫不存在 —— 随输出语言变化。
  • 可信度：每个来源后附 ✅实测 / ✅文档 / ⚠️推断。
  • 干什么是一段详细文字，回答：怎么调用、何时用、用了之后会发生什么。
  • 只读：skill 绝不改动你的配置；密钥、token、私有路径默认打码。

## Table 5 — MCP

| Name | Source | How to call | When to use | What it does |
|---|---|---|---|---|
| websearch | remote MCP, `mcp.exa.ai`, global config `opencode.jsonc:mcp.websearch` ✅verified | Agent calls it (tools `websearch_*`) | when you need live web results | Humans don't call it — the Agent invokes it automatically when it needs current information, returning clean text; reach for it for docs, news, or technical lookups. |
| context7 | remote MCP, `mcp.context7.com`, global config `opencode.jsonc:mcp.context7` ✅verified | Agent calls it (tools `context7_*`) | when you need up-to-date library docs | Humans don't call it — the Agent uses it to pull current library/framework documentation instead of relying on memory; the auth header contains a key, already masked. |
| pdf-mcp | local MCP, `pdf-mcp` command ✅verified | Agent calls it (tools `pdf_*`) | when you need to read or search a PDF | Humans don't call it — the Agent uses it to extract text, search, and pull tables out of PDFs, with SQLite-backed caching; reading-only, never for form filling.
